Behind many apps, a secret code is doing the talking, so what is an API key? Think of a hotel key card. It doesn't say who you are, it just opens the doors you paid for. An API key is a long secret code that a program shows a service, every time it makes a request. The service checks the code, then decides what that program may do, and how much. The catch: anyone who finds the key can use it, and the owner gets the bill. So never paste keys into public code. Next up: how Wi-Fi works. Follow PlainBytes for more tech, explained simply.
